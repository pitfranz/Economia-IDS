# Economia IDS

Quaderno di studio di Impresa e Decisioni Strategiche, in cinque pagine HTML autonome:

- **index.html**: Introduzione, modulo 0.
- **strategia.html**: dispensa completa illustrata di Strategia.
- **bilancio.html**: dispensa completa illustrata di Bilancio di esercizio.
- **esercizi.html**: guida agli esercizi, spiegata da zero.
- **parziale.html**: testo integrale di IDS_Integrata_Ottimizzata_Schemi_Bilancio.

Tutto il testo è scritto nelle pagine; i PDF sono allegati nella stessa cartella delle pagine. Il CSS è integrato in ogni HTML ed è identico per struttura, con il solo colore di accento diverso. Non servono dipendenze o procedure di compilazione. Aprire index.html per consultare il sito anche offline.

## Materiali

Le pagine di Strategia e Bilancio riprendono le dispense preparate individualmente. Per Introduzione non è stato recuperato il vecchio riassunto separato: il testo e il nuovo PDF dedicato sono un estratto del modulo 0 della dispensa integrata. Sono allegati i PDF dei professori per tutti e tre gli argomenti. La pagina del parziale allega sia la versione finale con schemi, sia il riassunto generale originale.

Nella guida agli esercizi, le ipotesi e le incongruenze degli appunti sono conservate come nella dispensa; i dati ricostruiti sono indicati esplicitamente.
